# Kodar

**Kodar** — платформа для роботи з ШІ-моделями: сайт, сервер-проксі та термінальний агент-кодер у стилі OpenCode.

Агент читає ваш проєкт, змінює файли, запускає команди — а ви контролюєте кожен крок.

## Структура

```
kodar/
  client/    — термінальний агент (Node.js 18+, без залежностей)
  server/    — сервер-проксі до Claude з обліком токенів (Node.js 18+)
  website/   — лендінг (статичний HTML, база для Next.js)
```

## Клієнт — швидкий старт

**Режим 1 — власний ключ Anthropic:**

1. Отримайте ключ на console.anthropic.com
2. `cd client`
3. Скопіюйте `.env.example` у `.env`, впишіть `AI_API_KEY=sk-ant-...`
4. `node src/index.js`
5. Пишіть завдання текстом, наприклад: `створи файл hello.js з функцією fibonacci`

**Режим 2 — через сервер Kodar (підписка/кредити):**

```
AI_BASE_URL=http://localhost:3000
AI_API_KEY=ak-...ключ_клієнта_з_сервера...
```

Обидва режими працюють через один протокол — сервер Anthropic-сумісний.

## Сервер — запуск

```
cd server
cp .env.example .env   # ANTHROPIC_API_KEY, ADMIN_TOKEN
node src/index.js
```

Ендпоінти:

| Метод | Шлях | Призначення |
|---|---|---|
| POST | `/v1/messages` | Anthropic-сумісний проксі зі списанням кредитів |
| GET | `/v1/usage` | Залишок кредитів клієнта |
| POST | `/admin/keys` | Створення ключа клієнта (заголовок `x-admin-token`) |

Кредити = токени (`input_tokens + output_tokens` за запит).

## Безпека

- Небезпечні команди і перезапис файлів — тільки після підтвердження користувача (y/N)
- Агент не може читати/писати файли поза робочою папкою
- Ключі зберігаються в `.env` (в git не потрапляють — див. `.gitignore`)
